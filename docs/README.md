# docs/ — พรีเซนเตชั่น + คู่มือการใช้งาน

ไฟล์ส่งมอบ 2 ไฟล์ สร้างจากสคริปต์ในโฟลเดอร์นี้ทั้งคู่ (แก้แล้วสร้างใหม่ได้เสมอ)

| ไฟล์ | คืออะไร |
|---|---|
| `Mix888-ระบบสั่งสินค้า-พรีเซนเตชั่น.pptx` | สไลด์ 21 แผ่น อธิบายระบบ · **อัปขึ้น Google Drive แล้วเปิดด้วย Google Slides ได้ทันที** |
| `คู่มือการใช้งาน-Mix888.pdf` | คู่มือ 43 หน้า มีสารบัญพร้อมเลขหน้า 64 หัวข้อ และภาพหน้าจอจริง 30 ภาพ |

## วิธีเอาสไลด์ขึ้น Google Slides
1. เปิด drive.google.com → **ใหม่ → อัปโหลดไฟล์** → เลือกไฟล์ `.pptx`
2. คลิกขวาที่ไฟล์ → **เปิดด้วย → Google Slides**
3. Google Slides จะแปลงให้เอง (บันทึกเป็นไฟล์ Slides แยกอีกไฟล์)
4. ฟอนต์ที่ใช้คือ **Sarabun** ซึ่งมีอยู่ใน Google Slides อยู่แล้ว หน้าตาจึงไม่เพี้ยน
5. โน้ตผู้บรรยายอยู่ครบทุกสไลด์ (เมนู **มุมมอง → บันทึกย่อของผู้บรรยาย**)

## ไฟล์ในโฟลเดอร์
| ไฟล์ | หน้าที่ |
|---|---|
| `build_deck.js` | สร้างไฟล์ `.pptx` ด้วย pptxgenjs — `node build_deck.js` |
| `preview_deck.mjs` | QA สไลด์: เรนเดอร์เป็นรูปในเบราว์เซอร์ + ตรวจข้อความล้นกรอบ (LibreOffice ใช้ไม่ได้บนเครื่อง cloud) |
| `deck-manifest.json` | โครงสไลด์ที่ `build_deck.js` เขียนไว้ให้ `preview_deck.mjs` อ่าน |
| `manual.html` | ต้นฉบับคู่มือ — **แก้เนื้อหาที่ไฟล์นี้** |
| `build_manual.mjs` | แปลง `manual.html` เป็น PDF — พิมพ์ 2 รอบ รอบแรกเพื่อหาว่าหัวข้อไหนอยู่หน้าไหน แล้วรอบสองเติมเลขหน้าลงสารบัญ |
| `img/` | ภาพหน้าจอความละเอียดเต็ม (ใช้ในสไลด์) |
| `img/small/` | ภาพย่อสำหรับฝังใน PDF (ลดขนาดไฟล์จาก 14 MB เหลือ ~7 MB) |

## สร้างใหม่
```bash
cd docs
npm i --no-save pptxgenjs pdfjs-dist@4   # ครั้งแรกครั้งเดียว
node build_deck.js && node preview_deck.mjs   # สไลด์ + QA
node build_manual.mjs                          # คู่มือ PDF
```

## ภาพหน้าจอมาจากไหน
ถ่ายจากหน้าเว็บจริง (`wnqz-6e9u-j4ym.html` และ `index.html`) รันในเบราว์เซอร์ Chromium
โดยแทนที่ตัวเชื่อมฐานข้อมูลด้วยตัวปลอม แล้วใส่ข้อมูลตัวอย่างเข้าไป — **ไม่มีข้อมูลลูกค้าจริงในภาพ**
ชื่อร้าน ชื่อคน ตัวเลขยอดขายทั้งหมดเป็นข้อมูลสมมติ

สคริปต์ที่ใช้ถ่ายอยู่ใน `tools/` — ต้องโคลน repo `pages` (github.com/thananant/Mix888)
ไว้ที่ `/home/user/thananant/mix888` ก่อน แล้วรัน

```bash
cd docs/tools
node shot.mjs     # หน้าหลังบ้าน 29 ภาพ
node shot2.mjs    # หน้าสั่งของฝั่งลูกค้าบนมือถือ 4 ภาพ
```

| ไฟล์ใน tools/ | หน้าที่ |
|---|---|
| `stub.js` | ตัวปลอมของ Supabase client — ให้หน้าเว็บเปิดได้โดยไม่ต่อฐานข้อมูลจริง |
| `mock.js` | ข้อมูลตัวอย่าง (เซลล์ ลูกค้า สินค้า ออเดอร์ บิล) |
| `shot.mjs` | เปิดหน้าหลังบ้าน ใส่ข้อมูลตัวอย่าง ไล่ถ่ายทีละหน้า |
| `shot2.mjs` | เปิดหน้าสั่งของฝั่งลูกค้าในขนาดมือถือ ถ่าย 4 จังหวะ |

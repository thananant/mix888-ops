บทที่ 1รู้จักระบบก่อนเริ่มใช้

ถ้าคุณเพิ่งเข้ามาทำงาน อ่านบทนี้บทเดียวก็พอจะเห็นภาพว่าระบบทำอะไรให้เราบ้าง แล้วเราต้องทำอะไรเอง

1.1 ระบบนี้ทำอะไรได้บ้าง

ระบบสั่งสินค้า Mix Fresh 168 เป็นเว็บแอปที่เขียนขึ้นเองสำหรับธุรกิจขายส่งวัตถุดิบหม้อไฟ/หม่าล่าโดยเฉพาะ ทำงานครบตั้งแต่ลูกค้ากดสั่งของ จนถึงเงินเข้าและปิดยอด ในระบบเดียว

ทำแทนเราได้รายละเอียด
รับออเดอร์จากลูกค้าลูกค้าแต่ละร้านมีลิงก์สั่งของของตัวเอง เปิดจากมือถือได้ทันที เห็นเฉพาะสินค้าและราคาที่เราจัดให้ร้านนั้น
ออกบิลกดปุ่มเดียว ระบบออกเลขบิล ตัดสต๊อกแบบ FIFO วาดรูปบิล และส่งเข้ากลุ่มไลน์ของร้านให้เอง
คุมสต๊อกรับของเข้า โอนระหว่างคลัง นับสต๊อก และคิดต้นทุนจริงแบบเข้าก่อนออกก่อน
ตามหนี้รู้ว่าบิลไหนค้าง ค้างมานานเท่าไหร่ ใครเป็นคนรับยอด และสลิปใบไหนยังไม่จับคู่บิล
วางแผนสั่งซื้อคำนวณจากยอดขายจริงย้อนหลังว่ารอบหน้าต้องสั่งอะไรกี่ชิ้น
ดูแลลูกค้าบอกว่าร้านไหนใกล้ถึงรอบสั่ง ร้านไหนหายไปนาน และส่งข้อความ/โปรโมชั่นหาหลายร้านพร้อมกันได้
ทำงานอัตโนมัติออกบิลอัตโนมัติทุก 3 นาที และส่งสรุปออเดอร์เข้ากลุ่มกลางทุกเช้า 06:00 น. แม้ไม่มีใครเปิดคอม

1.2 ระบบประกอบด้วยอะไรบ้าง

ระบบมี 5 ส่วน แต่ทุกส่วนใช้ฐานข้อมูลชุดเดียวกัน ตัวเลขจึงตรงกันเสมอ

ส่วนประกอบหน้าที่
หน้าสั่งของของลูกค้าเว็บหน้าเดียวบนมือถือ ลูกค้าเปิดจากลิงก์เฉพาะร้าน ไม่ต้องโหลดแอป ไม่ต้องสมัครสมาชิก
หน้าหลังบ้านหน้าเว็บที่พนักงานใช้ทำงาน มี 22 หน้างาน แบ่งเป็น 8 กลุ่มเมนู
ฐานข้อมูลบนคลาวด์เก็บข้อมูลทุกตาราง เก็บไฟล์รูปบิลและสลิป และคิดสต๊อก FIFO ให้ฝั่งเซิร์ฟเวอร์
รอบงานอัตโนมัติตัวตั้งเวลาบนคลาวด์ที่คอยออกบิลและส่งสรุปให้เอง
ตัววาดบิลบน NASเครื่อง NAS ในออฟฟิศ ทำหน้าที่วาดรูปบิลเต็มรูปแบบ (มีบาร์โค้ดและลายเซ็น) ประมาณ 1.4 วินาทีต่อใบ
ถ้า NAS ล่มจะเป็นยังไง บิลใบไหนค้างเกิน 10 นาที ระบบบนคลาวด์จะเข้ามาวาดแทนด้วยเทมเพลตเรียบง่ายให้อัตโนมัติ ลูกค้ายังได้บิลตามปกติ แค่หน้าตาเรียบกว่าเดิม

1.3 คำศัพท์ที่ต้องรู้ก่อน

คำพวกนี้จะโผล่ทั่วทั้งระบบ ถ้าเข้าใจตั้งแต่ต้นจะอ่านหน้าจอออกทันที

คำหมายความว่า
ออเดอร์ (SO)รายการที่ลูกค้าสั่งเข้ามา ยังไม่ใช่บิล ยังแก้ได้ ยกเลิกได้ และยังไม่ตัดสต๊อกจริง (แค่จองไว้)
บิล (MF…)เอกสารเรียกเก็บเงินที่ออกจากออเดอร์ ตอนออกบิลระบบจะตัดสต๊อกจริงและกินเลขบิลไป 1 เลข
รอบตัดบิลเวลาที่ใช้แบ่งว่า "ออเดอร์วันไหน" เช่น ตั้ง 18:00 น. แปลว่ารอบคือเมื่อวาน 18:00 ถึงวันนี้ 18:00
FIFOวิธีคิดต้นทุน "เข้าก่อนออกก่อน" — ของที่รับเข้ามาก่อนจะถูกตัดขายก่อน ต้นทุนจึงเป็นราคาจริงของล็อตนั้น
ล็อตของชุดหนึ่งที่รับเข้ามาพร้อมกัน มีราคาทุนของตัวเอง
ยอดจองของที่ลูกค้าสั่งแล้วแต่ยังไม่ออกบิล กันไว้ไม่ให้ขายซ้ำ
โกดัง / คลังที่เก็บของ แยกยอดคงเหลือกันได้ เช่น โกดังลาดพร้าว กับหน้าร้าน
เซลล์พนักงานขายที่ดูแลร้าน มีรหัส 3 ตัวอักษร ใช้เป็นตัวนำหน้ารหัสลูกค้า
กลุ่มไลน์ของร้านกลุ่มไลน์ที่มีลูกค้าร้านนั้นอยู่ ระบบส่งบิลเข้ากลุ่มนี้
กลุ่มกลางกลุ่มไลน์ของทีมเราเอง ใช้รับแจ้งออเดอร์ใหม่และสรุปประจำวัน
PIN 6 หลักรหัสที่ลูกค้าต้องใส่ก่อนกดยืนยันสั่งของ กันคนอื่นสั่งแทนร้าน

1.4 ใครทำอะไรได้บ้าง

บทบาททำได้ทำไม่ได้
adminทุกอย่าง รวมถึงเพิ่ม/แก้ผู้ใช้ ตั้งค่าระบบ และอนุมัติคำขอแก้บิลที่ส่งของแล้ว—
staffงานประจำวันทั้งหมด: รับออเดอร์ ออกบิล รับยอด จัดการสต๊อก ลูกค้า สินค้าเข้าหน้า "ผู้ใช้ระบบ" ไม่ได้ · แก้บิลที่ส่งของแล้วหรือรับยอดแล้วต้องส่งคำขอให้ admin อนุมัติ
หน้าต้นทุนสินค้าล็อกแยกอีกชั้น ไม่ว่าจะเป็น admin หรือ staff ถ้าจะเปิดดูต้นทุนและกำไร ต้องใส่รหัสตัวเลข 6 หลักของหน้านั้นอีกครั้ง

บทที่ 2เริ่มใช้งานครั้งแรก

บทนี้พาเปิดหน้าเว็บ เข้าสู่ระบบ และทำความรู้จักหน้าจอทีละส่วน

2.1 เข้าสู่ระบบ

  1. เปิดเบราว์เซอร์ (แนะนำ Google Chrome) แล้วเข้าลิงก์หน้าหลังบ้านที่หัวหน้างานให้ไว้
    • แนะนำให้กด บุ๊กมาร์ก ไว้ครั้งเดียว จะได้ไม่ต้องพิมพ์ใหม่ทุกวัน
  2. จะเจอหน้าเข้าสู่ระบบตามภาพด้านล่าง
  3. กรอก ชื่อผู้ใช้ — เป็นตัวอักษรอังกฤษพิมพ์เล็ก เช่น somchai
  4. กรอก รหัสผ่าน ที่ได้รับมา
  5. กดปุ่ม เข้าสู่ระบบ
ถ้าขึ้นว่า "ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง" เช็ค 3 อย่างตามลำดับ: (1) พิมพ์ชื่อผู้ใช้เป็นตัวเล็กทั้งหมดหรือยัง (2) ปุ่ม Caps Lock ค้างอยู่ไหม (3) แป้นพิมพ์เป็นภาษาไทยอยู่หรือเปล่า — ถ้ายังเข้าไม่ได้ ให้ admin ตั้งรหัสผ่านใหม่ให้ในหน้า "ผู้ใช้ระบบ"
ระบบจำการเข้าสู่ระบบให้ เข้าครั้งเดียวแล้วปิดแท็บไป เปิดใหม่ในเครื่องเดิมมักจะเข้าได้เลยโดยไม่ต้องกรอกซ้ำ ถ้าใช้เครื่องที่คนอื่นใช้ด้วย ให้กด ออกจากระบบ มุมล่างซ้ายทุกครั้ง

2.2 ทำความรู้จักหน้าจอ

เมื่อเข้าระบบได้ จะเจอหน้า ภาพรวม เป็นหน้าแรกเสมอ

ส่วนของหน้าจอคืออะไร
แถบซ้ายมือ (สีแดง)เมนูทั้งหมด กดหัวข้อเพื่อกางเมนูย่อย · ล่างสุดบอกว่าตอนนี้ใครเข้าระบบอยู่ และมีปุ่มออกจากระบบ
ใต้โลโก้ตัวเลขเวอร์ชันหน้าเว็บ เช่น build 25/08-A — เวลาแจ้งปัญหาให้บอกเลขนี้ด้วยเสมอ
ปุ่มช่วงเวลามุมขวาบนวันนี้ · 7 วัน · เดือนนี้ หรือเลือกเดือน/ช่วงวันที่เอง — การ์ดและกราฟทั้งหน้าจะเปลี่ยนตาม
การ์ดสรุป 8 ใบยอดขาย กำไร ออเดอร์ค้าง ยอดค้างจ่าย มูลค่าสต๊อก ของเสีย และลูกค้าใหม่ (บางใบกดเข้าไปดูรายละเอียดได้)

บทที่ 3ตั้งค่าระบบครั้งแรก (สำหรับ admin)

ทำครั้งเดียวตอนเริ่มต้น แล้วแทบไม่ต้องกลับมาแก้อีก — ถ้าคุณเป็น staff ข้ามไปบทที่ 4 ได้เลย

3.1 เข้าหน้าตั้งค่า

  1. ที่เมนูซ้ายมือ กด ผู้ใช้ เพื่อกางเมนูย่อย
  2. กด ผู้ใช้ อีกครั้ง (เมนูย่อยอันบน)

3.2 ตั้งกลุ่มไลน์กลาง

กลุ่มกลางคือกลุ่มไลน์ของทีมเราเอง ใช้รับแจ้งออเดอร์ใหม่และสรุปประจำวัน

  1. เชิญบอทของระบบเข้ากลุ่มไลน์ของทีม
  2. พิมพ์ id ในกลุ่มนั้น บอทจะตอบรหัสกลุ่มกลับมา (ขึ้นต้นด้วยตัว C)
  3. คัดลอกรหัสนั้นมาวางในช่อง LINE Group ID กลุ่มกลาง
  4. กด บันทึกตั้งค่า

3.3 กรอกข้อมูลบริษัทและหัวบิล

  1. ในหัวข้อ 🏢 ข้อมูลบริษัท กรอกชื่อบริษัท เลขผู้เสียภาษี 13 หลัก ที่อยู่ เบอร์ และอีเมล
  2. กด บันทึกข้อมูลบริษัท
  3. เลื่อนลงไปหัวข้อ 🧾 ข้อมูลบนหัวบิล กรอกเบอร์กลางและอีเมลกลางไว้เป็นค่าสำรอง
  4. กด บันทึกข้อมูลบิล
ค่าสำรองใช้เมื่อไหร่ เบอร์และอีเมลบนหัวบิลจะดึงจากเซลล์ที่ดูแลร้านนั้นก่อนเสมอ ถ้าร้านไหนยังไม่มีเซลล์ ระบบจึงจะใช้ค่ากลางที่ตั้งไว้

3.4 ใส่วันหยุดพิเศษ

วันหยุดที่ใส่ไว้ ระบบจะไม่ส่งสรุปออเดอร์ตอนเช้า และจะยกออเดอร์ไปรวมในรอบของวันเปิดถัดไปให้

  1. ที่หัวข้อ 📅 วันหยุดพิเศษ เลือกวันที่
  2. ใส่หมายเหตุ เช่น "วันสงกรานต์"
  3. กด + เพิ่มวันหยุด
ไม่ต้องใส่วันอาทิตย์ระบบข้ามวันอาทิตย์ให้อัตโนมัติอยู่แล้ว

3.5 เพิ่มผู้ใช้ใหม่

  1. เลื่อนลงมาที่การ์ด เพิ่มผู้ใช้
  2. กรอก ชื่อผู้ใช้ เป็นภาษาอังกฤษตัวเล็ก (ระบบบังคับให้เป็นตัวเล็กอยู่แล้ว)
  3. กรอก ชื่อที่แสดง เป็นภาษาไทยได้ เช่น "สมชาย" — ชื่อนี้จะไปโผล่ในช่อง "คนออกบิล" "คนรับยอด" ฯลฯ
  4. เลือก บทบาท: staff สำหรับพนักงานทั่วไป หรือ admin สำหรับคนที่ต้องจัดการผู้ใช้ได้
  5. ตั้ง รหัสผ่าน
  6. กด บันทึก
เวลาแก้ผู้ใช้เดิม ถ้าไม่ต้องการเปลี่ยนรหัสผ่าน ให้เว้นช่องรหัสผ่านว่างไว้ ถ้าพิมพ์อะไรลงไปจะกลายเป็นรหัสใหม่ทันที

3.6 สำรองข้อมูล

  1. ที่หัวข้อ 💾 สำรองข้อมูล กด ⬇️ ดาวน์โหลดไฟล์สำรอง
  2. รอจนขึ้นว่าเสร็จ แล้วเก็บไฟล์ไว้ในไดรฟ์หรือฮาร์ดดิสก์สำรอง
ทำอย่างน้อยสัปดาห์ละครั้ง ไฟล์สำรองเก็บข้อมูลทุกตาราง แต่ไม่รวมรูปภาพที่อยู่ในที่เก็บไฟล์ ถือเป็นตาข่ายกันพลาดชั้นสุดท้ายของร้าน

บทที่ 4ตั้งต้นข้อมูลหลัก: เซลล์ · สินค้า · ลูกค้า

สามอย่างนี้ต้องทำตามลำดับ เพราะรหัสลูกค้าวิ่งต่อจากรหัสเซลล์ และลูกค้าจะสั่งของได้ก็ต่อเมื่อมีสินค้าจัดให้แล้ว

1
เพิ่มเซลล์ตั้งรหัส 3 ตัวอักษร
2
เพิ่มสินค้าตั้ง SKU ราคา หน่วย
3
เพิ่มลูกค้าเลือกเซลล์ก่อนเสมอ
4
จัดสินค้าเลือกของ + ราคาเฉพาะร้าน
5
ส่งลิงก์ผูกกลุ่มไลน์ + ตั้ง PIN

4.1 เพิ่มเซลล์

  1. เมนูซ้าย → เซลล์ → เซลล์
  2. กรอก รหัสเซลล์ เป็นตัวอักษรอังกฤษพิมพ์ใหญ่ 3 ตัวพอดี เช่น SMC
  3. กรอก ชื่อเซลล์, เบอร์โทร 10 หลัก และ อีเมล
  4. กด บันทึก
รหัสเซลล์สำคัญมาก รหัสนี้จะกลายเป็น 3 ตัวหน้าของรหัสลูกค้าทุกร้านที่เขาดูแล เช่น เซลล์ SMC → ลูกค้าได้รหัส SMC00001, SMC00002 ไล่ไปเรื่อย ๆ ตั้งแล้วไม่ควรเปลี่ยน เพราะต้องไล่แก้รหัสลูกค้าทั้งหมดตาม · เบอร์และอีเมลของเซลล์จะขึ้นบนหัวบิลของร้านที่เขาดูแล
ลบเซลล์ไม่ได้ เซลล์ที่ยังมีลูกค้าดูแลอยู่จะลบไม่ได้ ต้องย้ายลูกค้าไปเซลล์คนอื่นให้หมดก่อน

4.2 เพิ่มสินค้า

  1. เมนูซ้าย → สินค้า → สินค้า
  2. ที่การ์ด เพิ่มสินค้า เลือก หมวดสินค้า ก่อน — ระบบจะรันรหัส SKU ให้อัตโนมัติตามหมวด
    • ถ้ายังไม่มีหมวดที่ต้องการ กดลิงก์ จัดการหมวด เพื่อเพิ่มหมวดใหม่
  3. กรอก ชื่อสินค้า ให้เป็นชื่อที่ลูกค้าอ่านแล้วเข้าใจ เพราะชื่อนี้จะไปขึ้นบนหน้าสั่งของและบนบิล
  4. กรอก หน่วยขาย เช่น ลัง / ถุง / แพ็ค / ขวด
  5. กรอก ราคากลาง — ใช้เป็นราคาตั้งต้นสำหรับร้านที่ยังไม่ได้ตั้งราคาเฉพาะ
  6. กรอกตัวเลขคุมสต๊อก
    • เตือนใกล้หมด — เหลือน้อยกว่านี้จะขึ้นเตือนในหน้าภาพรวม
    • Safety Stock — ระดับที่ควรมีติดคลังไว้เสมอ ใช้คำนวณใบโอนและแผนสั่งซื้อ
    • Max Stock — เพดานที่ไม่ควรเกิน ใช้คำนวณจำนวนที่ควรเรียกของ
  7. ถ้ามี ให้ติ๊ก ซัพพลายเออร์ ที่ขายสินค้าตัวนี้ (ติ๊กได้หลายราย)
  8. กด 📷 เลือกรูป เพื่อใส่รูปสินค้า (ไม่บังคับ แต่ช่วยให้ลูกค้าสั่งถูกตัวมาก)
  9. กด บันทึก
มีสินค้าเยอะมาก ใช้ปุ่ม นำเข้า CSV เพื่ออัปทีเดียวหลายรายการ และ ส่งออก CSV เพื่อดึงรายการปัจจุบันออกมาแก้ใน Excel ได้
อย่ากรอกสต๊อกเริ่มต้นถ้าจะรับของเข้าอยู่แล้ว ช่อง สต๊อกเริ่มต้น มีไว้ตอนย้ายข้อมูลเข้าระบบครั้งแรกเท่านั้น ของที่รับเข้ามาจริงควรบันทึกผ่านหน้า รับสินค้า เสมอ เพื่อให้ระบบสร้างล็อตและรู้ต้นทุน FIFO

4.3 เพิ่มลูกค้าใหม่

  1. เมนูซ้าย → ลูกค้า → ลูกค้า
  2. เลือก เซลล์ที่ดูแล ก่อนเป็นอันดับแรก — รหัสลูกค้าจะรันต่อจากรหัสเซลล์ให้อัตโนมัติ
  3. กรอก ชื่อร้าน
  4. ส่วน 🧾 ข้อมูลออกบิล — ข้อมูลชุดนี้จะไปขึ้นบนบิล
    • ชื่อลูกค้า (ผู้ติดต่อ) — ชื่อคนที่เราคุยด้วย
    • เบอร์โทร — ต้องเป็นตัวเลข 10 หลักพอดี
    • เลขผู้เสียภาษี — 13 หลัก ถ้าไม่มีเว้นว่างได้
    • ที่อยู่ — พิมพ์รหัสไปรษณีย์ 5 หลักก่อน ระบบจะเติมจังหวัด/อำเภอให้ แล้วค่อยเลือกตำบล
  5. ส่วน 🚚 ข้อมูลจัดส่ง — ถ้าที่อยู่ส่งของเหมือนที่อยู่บิล กดปุ่ม คัดลอกจากข้อมูลบิล ได้เลย
    • ชื่อผู้รับของ และ เบอร์ผู้รับ — ใช้ตอนเรียกรถส่งของ
    • Google Map Link — วางลิงก์แผนที่ ช่วยคนส่งของหาไม่หลง และใช้ปักหมุดในหน้าแผนที่ลูกค้า
    • เวลารับของ — ช่วงเวลาที่ร้านสะดวกรับ
    • วิธีจัดส่ง — Lalamove / BI / แพ็คของ / มารับเอง (ใช้จัดกลุ่มในสรุปประจำวัน)
  6. เลือก ประเภทบิล ที่ร้านนี้ต้องการ (บิลเงินสด หรือบิลเต็มรูปแบบ)
  7. ถ้าร้านนี้ไม่ควรเห็นราคา ให้ติ๊ก 🙈 ซ่อนราคาจากหน้าสั่งของ (ใช้กรณีเจ้าของร้านให้ลูกน้องเป็นคนกดสั่ง)
  8. กด บันทึก
ระบบเตือนข้อมูลซ้ำให้ ถ้าชื่อร้าน ชื่อผู้ติดต่อ เบอร์ หรือที่อยู่ ไปตรงกับลูกค้าของเซลล์คนอื่น ระบบจะเด้งเตือนพร้อมบอกว่าซ้ำกับร้านไหนของใคร ให้อ่านก่อนกดยืนยัน จะได้ไม่แย่งลูกค้ากันเองโดยไม่ตั้งใจ
ร้านที่มีหลายสาขา ให้สร้างร้านหลักก่อน แล้วสร้างสาขาเป็นลูกค้าอีกราย โดยเลือกช่อง เป็นสาขาของร้าน ให้ชี้ไปที่ร้านหลัก

4.4 จัดสินค้าให้ลูกค้า และตั้งราคาเฉพาะร้าน

ขั้นนี้ห้ามข้าม — ถ้ายังไม่จัดสินค้า ลูกค้าเปิดลิงก์มาจะเห็นหน้าว่างเปล่า

  1. เมนูซ้าย → ลูกค้า → จัดสินค้า
  2. ค้นหาและเลือกร้านที่ต้องการในช่องด้านบน
  3. ติ๊กเครื่องหมาย ✓ หน้าสินค้าที่อยากให้ร้านนี้เห็นและสั่งได้
    • ใช้ปุ่ม ✓ เลือกที่แสดง เพื่อติ๊กทั้งหมดที่กรองอยู่ทีเดียว
  4. ถ้าร้านนี้ได้ราคาพิเศษ ให้พิมพ์ราคาลงในช่องราคาของสินค้านั้น (เว้นว่าง = ใช้ราคากลาง)
  5. กด บันทึก
ร้านใหม่ที่คล้ายร้านเดิม ใช้ 📋 คัดลอกการจัดสินค้าจากร้านอื่น เลือกร้านต้นทาง แล้วกด คัดลอกมาใส่ร้านนี้ — ประหยัดเวลาได้มาก
อยากรู้ว่าใครเปลี่ยนราคา กด 🕘 ประวัติแก้ราคา จะเห็นว่าใครแก้ราคาอะไร เมื่อไหร่

4.5 สร้างลิงก์สั่งของ ผูกกลุ่มไลน์ และตั้ง PIN

  1. กลับไปหน้า ลูกค้า แล้วหาแถวของร้านนั้นในตารางด้านล่าง
  2. กดปุ่มสร้าง/คัดลอกลิงก์สั่งของของร้าน แล้วส่งลิงก์นั้นให้ลูกค้า
    • แนะนำให้ลูกค้าปักหมุดลิงก์ไว้ในกลุ่มไลน์ของร้าน จะได้ไม่หาย
  3. ผูกกลุ่มไลน์ของร้าน: เชิญบอทเข้ากลุ่มของร้านนั้น แล้วพิมพ์ id ในกลุ่ม เอารหัสที่บอทตอบมาใส่ในช่อง LINE Group ID ของลูกค้ารายนั้น
  4. ตั้ง PIN 6 หลัก ให้ร้าน แล้วบอกรหัสนี้กับเจ้าของร้าน
ถ้ายังไม่ผูกกลุ่มไลน์ ตอนออกบิล ระบบจะบอกว่า "ลูกค้ายังไม่ผูกกลุ่ม LINE — บิลจะออกเป็นรูปให้เปิดดูแทน" บิลยังออกได้ตามปกติ แต่ต้องส่งให้ลูกค้าเอง
ลูกค้าลืม PIN ให้ลูกค้าพิมพ์ เปลี่ยน 123456 (ตามด้วยรหัสใหม่ที่ต้องการ) ในกลุ่มไลน์ของร้าน ระบบจะตั้งรหัสใหม่ให้เอง

บทที่ 5ฝั่งลูกค้า: สั่งของยังไง

บทนี้ไว้ใช้สอนลูกค้า หรือแคปหน้าจอส่งให้ลูกค้าดู — ทั้งหมดทำบนมือถือ ไม่ต้องโหลดแอป

5.1 เปิดลิงก์และเลือกสินค้า

  1. ลูกค้ากดลิงก์ที่เราส่งให้ (หรือลิงก์ที่ปักหมุดไว้ในกลุ่ม)
  2. ด้านบนจะขึ้นรหัสและชื่อร้านของตัวเอง ถ้าขึ้นชื่อร้านอื่นแปลว่าส่งลิงก์ผิด
  3. เลื่อนหาสินค้า หรือพิมพ์ค้นหาในช่อง 🔍 ค้นหาสินค้า
  4. กดปุ่ม + เพื่อเพิ่มจำนวน หรือ − เพื่อลด
  5. แถบล่างสุดจะรวมยอดให้ตลอด เมื่อพร้อมแล้วกด สั่งสินค้า
ป้ายสถานะสินค้า ลูกค้าจะเห็นแค่ พร้อมจำหน่าย / สินค้าใกล้หมด / สินค้าหมด ไม่เห็นตัวเลขคงเหลือจริงของเรา ส่วนสินค้าที่กำลังลดราคาจะมีป้าย 🔥 และถูกดันขึ้นไปอยู่บนสุด

5.2 ยืนยันและใส่ PIN

  1. ตรวจรายการในหน้ายืนยัน ถ้าผิดกด กลับไปแก้
  2. กด ✓ ยืนยันสั่งสินค้า
  3. ระบบจะขอ รหัส 6 หลักของร้าน — ใส่แล้วกด ✓ ยืนยัน
    • กรอกครั้งเดียว เครื่องนั้นจะจำให้ ครั้งต่อไปไม่ต้องกรอกอีก
  4. เมื่อสำเร็จจะขึ้นเครื่องหมายถูกสีเขียวพร้อมเลขออเดอร์
ลูกค้าดูประวัติเองได้ แท็บ 📋 ประวัติการสั่ง ด้านบน ให้ลูกค้าย้อนดูได้ว่าเคยสั่งอะไรไปบ้าง เลือกช่วง 7 / 30 / 90 วัน หรือกำหนดเอง
สั่งแล้วยกเลิกเองไม่ได้ ถ้าลูกค้าสั่งผิด ให้แจ้งเซลล์ แล้วเราไปแก้หรือยกเลิกให้ในหน้า ทำบิล (ดูหัวข้อ 6.4)

บทที่ 6งานประจำวัน: จากออเดอร์เป็นบิล

นี่คือหน้าที่ใช้บ่อยที่สุดในแต่ละวัน — อ่านบทนี้ให้จบก่อนลงมือจริง

1
ออเดอร์เข้าระบบจองสต๊อก + แจ้งกลุ่มกลาง
2
ตรวจ + ใส่ค่าส่งดูต้นทุน/กำไรก่อนตัดสินใจ
3
ออกบิลตัดสต๊อกจริง + กินเลขบิล
4
ส่งเข้าไลน์วาดรูปบิลส่งกลุ่มร้าน
5
ส่งของ + รับยอดต่อที่หน้าบัญชี

6.1 เปิดหน้าทำบิล

  1. เมนูซ้าย → งานขาย → ทำบิล
  2. ออเดอร์ที่ลูกค้าสั่งเข้ามาและยังไม่ออกบิล จะเรียงเป็นการ์ดอยู่ที่นี่

6.2 ออกบิล

  1. อ่านรายการในการ์ดให้ครบก่อนว่าตรงกับที่ตกลงกับลูกค้าไหม
  2. ถ้ามีค่าส่ง ใส่ตัวเลขในช่อง ค่าขนส่ง (฿)
    • ถ้าร้านนี้ส่งด้วย BI กด 🧮 ค่าส่ง BI ระบบจะคำนวณตามเรทของร้านให้
  3. ถ้ามีส่วนลด ใส่ในช่อง ส่วนลด (฿)
  4. ตรวจ ยอดเรียกเก็บ อีกครั้ง
  5. เลือกปุ่มที่จะกด
    • 🧾 ออกบิล + ส่ง LINE — ใช้เป็นปกติ ระบบออกบิล วาดรูป และส่งเข้ากลุ่มไลน์ของร้านให้เลย
    • ออกบิลเฉย ๆ — ออกบิลแต่ยังไม่ส่ง เอาไว้ใช้ตอนอยากตรวจก่อน หรือร้านยังไม่ผูกกลุ่มไลน์
  6. รอจนขึ้นข้อความยืนยัน แล้วการ์ดนั้นจะหายไปจากหน้านี้ (ย้ายไปอยู่หน้าบัญชีแล้ว)
ออกบิลแล้วเลขบิลจะถูกใช้ไปเลย ต่อให้ยกเลิกทีหลัง เลขบิลนั้นก็จะไม่ถูกนำกลับมาใช้ซ้ำ ดังนั้นตรวจให้ครบก่อนกด ถ้าต้องแก้ของในออเดอร์ ให้แก้ก่อนออกบิล (ข้อ 6.4) เพราะการแก้ตอนนั้นไม่กินเลขบิล

6.3 ออกบิลอัตโนมัติ และรอบตัดบิล

ถ้าไม่มีใครกดออกบิลเอง ระบบจะออกให้เองทุก 3 นาที สำหรับออเดอร์ที่ถึงรอบแล้ว

  1. ที่หัวหน้าทำบิล ดูช่อง เวลาตัดรอบบิล
  2. ปรับเวลาที่ต้องการ เช่น 18:00 แปลว่ารอบคือเมื่อวาน 18:00 ถึงวันนี้ 18:00
  3. กด บันทึกรอบ

ยกเว้นร้านที่ไม่อยากให้ออกบิลอัตโนมัติ

  1. กด ⛔ ยกเว้นร้าน (ออกบิลอัตโนมัติ)
  2. เลือกร้านที่ต้องการยกเว้น เช่น ร้านทดสอบ หรือร้านที่ต้องคุยราคาก่อนทุกครั้ง
  3. บันทึก — ออเดอร์ของร้านเหล่านี้จะรออยู่ในหน้าทำบิลจนกว่าเราจะกดออกเอง

6.4 แก้ออเดอร์ หรือยกเลิกออเดอร์

  1. หาการ์ดออเดอร์ที่ต้องการในหน้า ทำบิล
  2. กด ✏️ แก้ออเดอร์ เพื่อเพิ่ม/ลบสินค้า หรือแก้จำนวน แล้วบันทึก
    • การแก้ตรงนี้ไม่กินเลขบิล เพราะยังไม่ได้ออกบิล
  3. ถ้าจะยกเลิกทั้งใบ กด ❌ ยกเลิก — ระบบจะคืนยอดจองสต๊อกให้อัตโนมัติ

6.5 ส่งสรุปออเดอร์เข้ากลุ่มกลาง

สรุปนี้คือรายการที่ทีมจัดส่งใช้จัดของ แยกตามวิธีขนส่ง พร้อมที่อยู่ เบอร์ และลิงก์แผนที่

  1. ปกติระบบส่งให้เองทุกเช้า 06:00 น. ไม่ต้องทำอะไร
  2. ถ้าอยากส่งเดี๋ยวนี้ กด 📋 ส่งสรุปออเดอร์รอบนี้เข้าไลน์กลาง
  3. ถ้าอยากส่งเฉพาะช่วงเวลาที่กำหนดเอง ใส่วันเวลาในช่อง กำหนดเอง ทั้งสองช่อง แล้วกด 📤 ส่งสรุปช่วงนี้
  4. อยากดูก่อนว่าจะออกมาหน้าตาแบบไหน โดยยังไม่ส่งจริง กด 🔍 ทดลองสรุป (ไม่ส่งไลน์)
  5. อยากรู้ว่าที่ผ่านมาส่งไปแล้วกี่รอบ กด 🕘 ประวัติการส่งสรุป
ระบบกันส่งซ้ำให้แล้ว ต่อให้กดส่งพร้อมกันหลายคน หรือรอบอัตโนมัติวิ่งชนกัน สรุปรอบหนึ่งจะออกแค่ครั้งเดียวเสมอ

บทที่ 7บัญชี: ตามหนี้ รับยอด และรายจ่าย

หน้าบัญชีคือศูนย์กลางของทุกบิลที่ออกไปแล้ว — ตั้งแต่ยังไม่ส่งของ จนถึงเก็บเงินครบ

7.1 เปิดหน้าบัญชีและอ่านตาราง

  1. เมนูซ้าย → บัญชี → บัญชี
  2. ค่าเริ่มต้นจะกรองไว้ที่แท็บ ค้างจ่าย

ตัวกรองที่ใช้บ่อย

  • แท็บด้านบน — ค้างจ่าย / จ่ายแล้ว / ยกเลิกบิล / ทั้งหมด / 🧾 มีสลิป
  • เซลล์ · ขนส่ง · สถานะส่ง — เลือกซ้อนกันได้ เช่น "ของเซลล์ปรียา ที่ส่ง BI และยังรอส่ง"
  • ช่วงวันที่ — เลือกตั้งแต่/ถึง
  • ช่องค้นหา — พิมพ์เลขบิล เลขออเดอร์ หรือชื่อร้าน

7.2 รับยอด (บันทึกว่าเงินเข้าแล้ว)

  1. ใส่ชื่อตัวเองในช่อง ผู้ตรวจ ด้านบน (ปกติระบบเติมให้แล้ว)
  2. หาแถวบิลที่ต้องการ
  3. กดปุ่มรับยอดที่ท้ายแถว
  4. ถ้าลูกค้าจ่ายครบ ให้ยืนยันยอดเต็ม · ถ้าจ่ายบางส่วน ให้ใส่จำนวนที่ได้รับจริง
  5. ระบบจะบันทึกชื่อคนรับยอดและเวลาไว้ให้อัตโนมัติ
รับยอดผิดใบ กดปุ่มยกเลิกการรับยอดที่แถวเดิม ระบบจะคืนสถานะเป็นค้างจ่าย และเก็บประวัติไว้ให้ตรวจย้อนหลังได้

7.3 สลิปโอนเงิน

  1. แนบรูปสลิปเข้ากับบิลที่ตรงกัน
  2. ใช้แท็บ 🧾 มีสลิป เพื่อดูเฉพาะบิลที่มีสลิปแล้ว
  3. กด 🕵️ สลิปตกค้าง เพื่อดูสลิปที่ยังจับคู่กับบิลไม่ได้ แล้วจับคู่ให้เรียบร้อย

7.4 แก้บิล และยกเลิกบิล

  1. กดปุ่มแก้บิลที่ท้ายแถว
  2. ถ้าบิลนั้นยังไม่ส่งของและยังไม่รับยอด — แก้ได้เลย ระบบจะปรับสต๊อกและยอดให้ พร้อมเพิ่มเลขเวอร์ชันเป็น v.2
  3. ถ้าบิลนั้นส่งของแล้วหรือรับยอดแล้ว — ระบบจะสร้าง "คำขอแก้บิล" ส่งให้ admin
    • admin เข้าไปกด 🛎️ คำขอแก้บิล เพื่ออนุมัติ
    • เมื่ออนุมัติแล้ว ระบบจะแก้บิล ปรับสต๊อกที่โกดัง และคิดสถานะจ่ายใหม่ให้ทันที
  4. ถ้าจะยกเลิกทั้งใบ กดปุ่มยกเลิกบิล — บิลที่ยกเลิกจะไม่ถูกนับเป็นหนี้ค้างและไม่นับเป็นรายรับ แต่ยังดูย้อนหลังได้ในแท็บ ยกเลิกบิล

7.5 ดึงรายงานเป็น Excel

  1. เลือกเดือนในช่อง เดือน แล้วกด 📊 Excel รายเดือน
  2. หรือกรองรายการที่ต้องการไว้ก่อน แล้วกด ⬇️ Excel รายการนี้
    • ไฟล์นี้มี 2 ชีต: สรุปรายบิล และรายการสินค้าพร้อมต้นทุน/กำไร

7.6 บันทึกรายจ่าย (Petty Cash)

  1. เมนูซ้าย → บัญชี → รายจ่าย (Petty Cash)
  2. เลือก วันที่จ่าย และ หมวดค่าใช้จ่าย
  3. กรอก รายละเอียด และ จำนวนเงิน (สองช่องนี้บังคับ)
  4. เลือก วิธีจ่าย และใส่ ผู้จ่าย/สำรองจ่าย
  5. ถ่ายรูปใบเสร็จแนบในช่อง ใบเสร็จ (รูป)
  6. กด 💾 บันทึกรายจ่าย

บทที่ 8สต๊อกและคลังสินค้า

หัวใจคือ "ของเข้าต้องบันทึก ของออกระบบตัดให้" ถ้าทำครบ ตัวเลขในระบบจะตรงกับของจริงเสมอ

8.1 รับสินค้าเข้า

  1. เมนูซ้าย → สินค้า → รับสินค้า
  2. เลือก รับเข้าคลัง ว่าของกองนี้เข้าคลังไหน
  3. ใส่ ผู้ขาย / ที่มา (ไม่บังคับ แต่ใส่ไว้จะไล่ที่มาของล็อตได้)
  4. ใส่ชื่อ ผู้รับของ
  5. พิมพ์ชื่อสินค้าในช่องค้นหา แล้วกดเพิ่มเข้ารายการ
  6. ใส่จำนวนและราคาทุนต่อหน่วยของล็อตนี้ ทำซ้ำจนครบทุกตัว
  7. กด ✓ บันทึกรับเข้า
ราคาทุนต้องใส่ให้ถูก ตัวเลขนี้คือฐานของต้นทุน FIFO และกำไรทุกบิลที่ตัดจากล็อตนี้ ถ้าใส่ผิดจะทำให้กำไรทั้งเดือนเพี้ยน
บันทึกแล้วเห็นผลทันที สต๊อกเพิ่มทันที และหน้าสั่งของของลูกค้าจะเห็นตัวเลขใหม่แบบสด ๆ โดยไม่ต้องรีเฟรช

8.2 โอนของจากโกดัง

  1. เมนูซ้าย → สินค้า → โอนโกดัง
  2. เลือก จากโกดัง (ต้นทาง) และ ไปโกดัง (ปลายทาง)
  3. กด 🧮 คำนวณแนะนำเรียกของ ระบบจะเสนอจำนวนให้ตามสูตร
    • เรียก = (Max ถ้าตั้งไว้ ไม่งั้นใช้ Safety) + ยอดจองรอส่ง − ของคงเหลือปลายทาง
  4. ปรับจำนวนตามจริง หรือกด + เพิ่ม เพื่อใส่สินค้าเอง
  5. กด 💾 บันทึกใบโอน + แจ้ง LINE
  6. เมื่อของถึงปลายทาง ให้ไปที่หน้า รับสินค้า หัวข้อ 🚛 รอรับเข้าจากโกดัง แล้วกดยืนยันรับ
อยากได้ใบเรียกของเป็นรูป กด 🖼️ รูปสรุปโอนสินค้า จะได้รูปที่ส่งให้ทีมโกดังหยิบของได้เลย ชื่อสินค้ายาวจะถูกแบ่งเป็น 2 บรรทัดให้อ่านง่าย

8.3 นับ / ปรับสต๊อก

  1. เมนูซ้าย → สินค้า → นับ/ปรับสต๊อก
  2. เลือก โกดัง และ ชุดสินค้า ที่จะนับ
  3. กด 📄 PDF ใบเช็คสต๊อก (นับมือ) แล้วปริ้นไปนับที่คลัง
  4. กลับมากรอกจำนวนที่นับได้จริงลงในตาราง
    • แถวที่ขึ้นสีแดง คือนับได้ไม่ตรงกับระบบ
  5. กด ✓ ยืนยันผลนับ + สรุปเดินสต๊อก
ดูย้อนหลังได้ แท็บด้านบนมี ประวัติปรับสต๊อก, ประวัติแปลงสินค้า และ ประวัติการนับ เก็บไว้ให้ตรวจสอบได้ทุกครั้ง

8.4 ไล่ดูว่าของหายไปไหน

  1. เมนูซ้าย → สินค้า → เดินรายการสินค้า
  2. เลือกสินค้า ประเภทรายการ โกดัง และช่วงวันที่
  3. กด 🔎 ดูรายการ — จะเห็นทุกครั้งที่ของเข้าและออก พร้อมชื่อคนทำและเอกสารอ้างอิง
  4. อยากเก็บไว้วิเคราะห์ต่อ กด ⬇️ CSV

8.5 คลังสินค้า

  1. เมนูซ้าย → สินค้า → คลังสินค้า
  2. ดูยอดคงเหลือแยกตามคลังได้ที่ตารางด้านบน
  3. ถ้าจะเพิ่มคลังใหม่ กรอกชื่อคลัง ผู้ติดต่อ เบอร์ และที่อยู่ แล้วกด บันทึกคลัง
    • พิมพ์รหัสไปรษณีย์ 5 หลัก ระบบจะเติมจังหวัด/อำเภอให้อัตโนมัติ

8.6 ดูต้นทุนสินค้า

  1. เมนูซ้าย → ผู้ใช้ → ต้นทุนสินค้า
  2. ใส่ รหัส 6 หลัก ของหน้านี้ แล้วกด ปลดล็อก
    • ถ้ายังไม่เคยตั้ง ระบบจะให้ตั้งรหัสครั้งแรกตรงนี้
  3. ดูหรือแก้ต้นทุนได้ แล้วกด 💾 บันทึกที่แก้
  4. ใช้เสร็จกด 🔒 ล็อก ทุกครั้ง

บทที่ 9วางแผนและสั่งซื้อ

แทนที่จะเดาว่าต้องสั่งเท่าไหร่ ให้ระบบคำนวณจากยอดขายจริงย้อนหลังให้

9.1 แพลนการสั่งซื้อ

  1. เมนูซ้าย → แพลนสั่งซื้อ
  2. ตั้งค่าตัวเลข 4 ตัวด้านบน
    • ดูยอดขายย้อนหลัง — แนะนำ 90 วัน (ยิ่งยาวยิ่งแม่น)
    • รอของ (วัน) — สั่งแล้วกี่วันของถึง
    • รอบสั่งทุก (วัน) — เราสั่งถี่แค่ไหน
    • เผื่อฉุกเฉิน (วัน) — กันของขาดกรณีขายดีผิดปกติ
  3. เลือก คาดการณ์ยอด เป็น "ตามเทรนด์ (แนะนำ)"
  4. ติ๊ก เฉพาะที่ต้องสั่ง เพื่อกรองเอาเฉพาะตัวที่ขาด
  5. กด 🧮 คำนวณแผน
  6. อ่านผลในตาราง แล้วเลือกทำต่อ
    • 📋 คัดลอกใบสั่งซื้อ — ได้ข้อความไปวางส่งซัพพลายเออร์
    • 📦 บันทึกเป็นใบสั่งซื้อ — เก็บไว้ในระบบ แล้วตัดยอดตอนของมาถึง

สูตรที่ระบบใช้

เป้าหมาย = ขาย/วัน × (รอของ + รอบสั่ง + เผื่อ)

ค.1 เปิดใช้งาน "ลูกค้าใหม่รายวัน + ใครเป็นคนเพิ่ม"

  1. เปิดหน้าจัดการฐานข้อมูล แล้วเข้าส่วน SQL Editor
  2. ล้างแท็บให้ว่างก่อน แล้ววางเนื้อหาไฟล์ customers_created_by.sql ทั้งไฟล์
  3. กดรัน — คำสั่งนี้เพิ่มคอลัมน์ created_by ในตาราง customers
  4. อัปหน้าเว็บหลังบ้าน build 25/08-A ขึ้นแทนของเดิม
  5. เปิดหน้าเว็บใหม่ แล้วตรวจว่าเลข build ใต้โลโก้เปลี่ยนเป็น 25/08-A
ข้อมูลเก่าย้อนหลังไม่ได้ ลูกค้าที่มีอยู่ก่อนหน้านี้จะไม่มีชื่อคนกดเพิ่ม เพราะระบบไม่เคยเก็บไว้ หน้าจอจะแสดงชื่อเซลล์เจ้าของรหัสแทนพร้อมเครื่องหมาย * ส่วนลูกค้าที่เพิ่มหลังจากนี้จะเก็บชื่อจริงของคนที่ล็อกอินกดเพิ่ม

ค.2 กติกาเวลาแก้หน้าเว็บ

  • ทุกครั้งที่แก้หน้าเว็บ ต้องเปลี่ยนเลข build ใต้โลโก้ด้วยเสมอ จะได้รู้ว่าเครื่องไหนใช้เวอร์ชันอะไรอยู่
  • ก่อนแก้ ให้ดึงไฟล์ล่าสุดมาก่อน อย่าแก้ต่อจากสำเนาเก่า
  • แก้เสร็จให้ทดสอบหน้าที่แก้จริงก่อนเอาขึ้นใช้งาน

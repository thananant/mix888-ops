# ติดตั้งตัววาดบิลบน Synology NAS (DS925+ · DSM 7.2 · Container Manager)

ตัวนี้คือ "เครื่องวาดบิล" ที่รันบน NAS: ทุก ๆ 30 วินาทีจะเช็คว่ามีบิลที่ระบบออกอัตโนมัติ
แต่ยังไม่มีรูป (`image_url` ว่าง) แล้ววาดรูปบิลหน้าตาเหมือนที่หน้าเว็บวาดทุกประการ
(บาร์โค้ด ลายเซ็น ตัวหนังสือไทย) อัปโหลดขึ้น Supabase ให้อัตโนมัติ

## สิ่งที่ต้องมีก่อนเริ่ม

- NAS เปิดใช้แพ็กเกจ **Container Manager** แล้ว (ติดตั้งได้จาก Package Center)
- ไฟล์ทั้งโฟลเดอร์ `nas-renderer` นี้ (ต้องมี `nas-worker.js`, `bill-render.html`,
  `package.json`, `Dockerfile`, `docker-compose.yml`, `.dockerignore`, `.env.example`)
- คีย์ `service_role` ของ Supabase (ดูขั้นตอนที่ 2)

---

## ขั้นตอนที่ 1 — อัปโหลดโฟลเดอร์ขึ้น NAS

1. เปิด **File Station** บน DSM
2. เข้าไปที่แชร์โฟลเดอร์ **docker** (ถ้าไม่มี ให้สร้างแชร์โฟลเดอร์ชื่อ `docker` ก่อนใน
   Control Panel → Shared Folder)
3. สร้างโฟลเดอร์ใหม่ชื่อ **mix888-renderer** → ได้พาธ `/docker/mix888-renderer`
4. ลากไฟล์ทั้งหมดในโฟลเดอร์ `nas-renderer` จากคอมพิวเตอร์ ไปวางใน
   `/docker/mix888-renderer` (อัปโหลดทีละไฟล์ก็ได้ ตรวจให้ครบทุกไฟล์)

## ขั้นตอนที่ 2 — สร้างไฟล์ .env (ใส่กุญแจลับ)

1. ใน File Station เปิดโฟลเดอร์ `/docker/mix888-renderer`
2. คลิกขวาที่ไฟล์ `.env.example` → **Open with Text Editor**
   (ถ้ามองไม่เห็นไฟล์ที่ขึ้นต้นด้วยจุด ให้กด Settings ของ File Station แล้วติ๊ก
   แสดงไฟล์ซ่อน / หรืออัปโหลดไฟล์ที่เตรียมจากคอมแทน)
3. ไปเอาคีย์จาก Supabase: เข้า https://supabase.com/dashboard → เลือกโปรเจกต์ Mix888 →
   **Settings → API** → คัดลอกคีย์ **service_role** (ไม่ใช่ anon / publishable)
4. วางคีย์ลงบรรทัด `SERVICE_KEY=` (ต่อท้ายเครื่องหมาย = ไม่ต้องมีเว้นวรรค ไม่ต้องมีเครื่องหมายคำพูด)
5. **Save As** เป็นชื่อ **`.env`** (จุดนำหน้า ไม่มีนามสกุลอื่น) ไว้ในโฟลเดอร์เดียวกัน

> คำเตือน: คีย์ service_role ข้ามสิทธิ์ความปลอดภัยทั้งหมดของฐานข้อมูล
> เก็บไว้บน NAS เท่านั้น ห้ามเอาไปใส่ในหน้าเว็บ ห้ามส่งไลน์/อีเมลต่อให้ใคร

## ขั้นตอนที่ 3 — สร้างโปรเจกต์ใน Container Manager

1. เปิด **Container Manager** → แท็บ **Project** → กด **Create**
2. ตั้งค่า:
   - **Project name:** `mix888-renderer`
   - **Path:** กด Set path แล้วเลือก `/docker/mix888-renderer`
   - ระบบจะเจอไฟล์ `docker-compose.yml` เอง → เลือก **Use existing docker-compose.yml**
3. กด **Next** ไปเรื่อย ๆ (ไม่ต้องตั้ง Web portal ใด ๆ) แล้วกด **Done**
4. รอ build ครั้งแรกสักพัก (ต้องดาวน์โหลดอิมเมจ Chromium ~2 GB ใช้เวลาหลายนาที
   ขึ้นกับเน็ต) — สถานะโปรเจกต์จะเปลี่ยนเป็น **Running** เมื่อเสร็จ

## ขั้นตอนที่ 4 — ดู log ว่าทำงานจริง

1. Container Manager → **Container** → คลิกคอนเทนเนอร์ `mix888-renderer-…`
2. เปิดแท็บ **Log**
3. บรรทัดแรก ๆ ต้องเห็นประมาณนี้:
   ```
   [start] Mix888 NAS renderer · poll every 30000 ms · https://eqbzpgynzgdwvouuzfwt.supabase.co
   [browser] launching chromium + loading file:///app/bill-render.html
   ```
4. เวลามีบิลรอวาด จะเห็นบรรทัดแบบนี้ (บิลละ 1 บรรทัด):
   ```
   [poll] 2 bill(s) need drawing
   [bill] IV680801-013 pages=1 ms=4180
   ```
   ถ้าวาดใบไหนไม่สำเร็จจะขึ้น `FAILED: … (left queued)` — บิลใบนั้นจะยังค้างคิวไว้
   ให้ระบบสำรอง (edge function) จัดการต่อ ไม่หายไปไหน

## ขั้นตอนที่ 5 — ทดสอบของจริง

1. ที่หน้าเว็บหลังบ้าน ออกบิลอัตโนมัติ 1 ใบ (หรือหาบิลที่ยังไม่มีรูปในหน้าบัญชี)
2. รอไม่เกิน 1 นาที (ตามรอบ POLL_MS)
3. กด "ดูบิล" ที่หน้าเว็บ — ต้องเปิดรูปบิลได้ทันทีโดยไม่ขึ้นข้อความ "กำลังวาดให้ รอสักครู่"
4. เช็คใน log ต้องมีบรรทัด `[bill] <เลขบิล> pages=… ms=…` ของบิลใบนั้น

## เปิดสวิตช์ nas_mode (สำคัญมาก — ทำเป็นขั้นสุดท้ายเท่านั้น)

กฎ: **เปิด `nas_mode` เป็น `'1'` ได้ก็ต่อเมื่อยืนยันแล้วว่าคอนเทนเนอร์รันอยู่จริง**
(ผ่านขั้นตอนที่ 4-5 แล้วเท่านั้น)

- เปิด: ไปที่ตาราง `settings` ใน Supabase (Table Editor) ตั้งค่า key `nas_mode` = `'1'`
- ถ้าจะ **ปิด NAS นานๆ** (ซ่อมเครื่อง ย้ายบ้าน ไฟดับบ่อย): ตั้ง `nas_mode` กลับเป็น `'0'`
  ก่อน เพื่อให้ระบบสำรองบนคลาวด์กลับมาวาดบิลแทน ไม่งั้นบิลจะค้างไม่มีรูป

## การหยุด / เริ่มใหม่

- **หยุดชั่วคราว:** Container Manager → Project → `mix888-renderer` → **Stop**
  (ปิดสั้น ๆ ไม่ต้องแตะ nas_mode — บิลที่ค้างจะถูกวาดทันทีที่สตาร์ทกลับมา)
- **เริ่มใหม่:** ปุ่ม **Start** ที่เดียวกัน (ตั้ง restart: unless-stopped ไว้แล้ว —
  NAS รีบูตเองคอนเทนเนอร์จะกลับมารันอัตโนมัติ)
- **ปิดยาว:** ตั้ง `nas_mode` = `'0'` ก่อน แล้วค่อย Stop
- **อัปเดตโค้ด:** อัปโหลดไฟล์ใหม่ทับใน `/docker/mix888-renderer` → Project →
  **Action → Build** → Start ใหม่

## แก้ปัญหาเบื้องต้น

| อาการใน log | สาเหตุ / วิธีแก้ |
|---|---|
| `SUPABASE_URL and SERVICE_KEY must be set` | ไฟล์ `.env` ไม่มี หรือชื่อไม่ใช่ `.env` เป๊ะ ๆ — กลับไปขั้นตอนที่ 2 |
| `GET bills -> 401` | คีย์ผิด/ไม่ครบ — คัดลอก service_role ใหม่ทั้งบรรทัด |
| `renderBill returned no A4 pages` | เปิดดูบิลใบนั้นที่หน้าเว็บเพื่อวาดด้วยมือ แล้วแจ้งผู้ดูแลระบบ |
| ตัวหนังสือจีนเป็นสี่เหลี่ยม | อิมเมจถูก build โดยข้ามขั้นติดตั้งฟอนต์ — สั่ง Build ใหม่แบบไม่ใช้ cache |
